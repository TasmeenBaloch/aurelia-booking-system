# Aurelia Home Appliances — Service Booking System

A professional front-end booking and reservation system developed for Aurelia Home Appliances as part of a Week 3 internship project.

The system allows customers to select a service and appliance, choose an available appointment date and time, enter their contact details, review their booking, and receive a booking confirmation with a unique reference number.

## Features

- Service selection
- Appliance selection
- Interactive calendar
- Date and appointment time selection
- Customer details form
- Form validation
- Booking review before confirmation
- Automatic booking reference generation
- Booking confirmation screen
- "Book Another Service" option
- Responsive design for different screen sizes
- Professional home appliance service interface

## Services Available

- Installation
- Delivery
- Home Consultation
- Service Visit

## Appliances Available

- Refrigerator
- Washing Machine
- Air Conditioner
- Microwave Oven
- Dishwasher

- HTML5
